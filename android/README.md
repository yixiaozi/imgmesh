# imgmesh Android

用 Android Studio 打开这个目录，或在这里执行 `./gradlew :app:assembleDebug`。应用包名是 `com.imgmesh.app`，最低系统是 Android 10。

这台设备可以登记名称、填写介绍、城市和联系方式，查找别人，打开带 `#k=` 的完整链接，按网格查看照片和身份证，并把解密后的照片存进系统相册。保存整组照片会打开自动保存，以后这条链接新增的照片会在再次打开时存进相册。也可以单独开关「自动保存新增照片」。保存会写到照片身份证的「谁保存了」。

发出的链接可以继续添加照片。服务器的设备类型是 `ios`、`web` 和 `desktop`，没有单独的安卓类型，所以注册和访问记录使用 `web`，在活动记录里显示为浏览器。创建分享、继续添加和撤销仍要求绑定 Apple；安卓没有 Sign in with Apple，点这些操作时会提示先用 Apple 登录。链接请粘贴完整内容；系统打开 `https://imgmesh.com/s/…` 时通常会丢掉井号后的密钥。
