# imgmesh Android

用 Android Studio 打开这个目录，或在这里执行 `./gradlew :app:assembleDebug`。应用包名是 `com.imgmesh.app`，最低系统是 Android 10。

这台设备可以登记名称、填写介绍、城市和联系方式，查找别人，打开带 `#k=` 的完整链接，按网格查看照片和身份证，并把解密后的照片存进系统相册。保存会写到照片身份证的「谁保存了」。

服务器目前只接受 `ios` 和 `web` 两种设备，创建分享还要求绑定 Apple。安卓注册时使用 `web`，因此还不能在这里新建分享。链接请粘贴完整内容；系统打开 `https://imgmesh.com/s/…` 时通常会丢掉井号后的密钥。
