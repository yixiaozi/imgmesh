安装和使用

App 还没上架。用 Xcode 装到自己的 iPhone 就能发照片。收到链接的人不用装 App，用浏览器就能看。

先准备这些

  • 一台 Mac，安装 Xcode 16。
  • 一部 iPhone，系统为 iOS 17 或更新。用数据线连上 Mac，并在手机上点「信任」。
  • 已加入 Apple Developer Program 的付费账号。Sign in with Apple 和从链接直接打开 App 都需要这个账号。

装到 iPhone

  1. 在 Mac 上克隆仓库。 
    git clone https://github.com/yixiaozi/imgmesh.git
  2. 双击打开 ios/Imgmesh.xcodeproj。
  3. 左侧点工程名 Imgmesh，选中 App 目标。打开 Signing & Capabilities，勾选 Automatically manage signing，Team 选你的开发团队。Bundle Identifier 保持 com.imgmesh.app。
  4. 确认能力里有 Sign in with Apple，以及 Associated Domains 的 applinks:imgmesh.com。工程里已经写好；Xcode 要求登记 App ID 时，让它自动处理。
  5. Xcode 顶部的运行设备选这台 iPhone，点运行。装好后打开 App。
  6. 如果 iPhone 提示开发者不受信任：打开「设置 → 通用 → VPN 与设备管理」，点你的开发者描述文件，再点信任。

让链接直接打开 App

这一步做完之前，把完整链接粘贴进 App 也能打开。做完之后，在 iPhone 上点 https://imgmesh.com/s/… 会进入 imgmesh。

  1. 打开 developer.apple.com/account，在 Membership details 里复制 Team ID。它是 10 位字符。
  2. 在服务器的 /etc/imgmesh/api.env 里写上这一行，把占位换成你的 Team ID。 
    APPLE_TEAM_ID=你的TeamID
  3. 重启 API。 
    systemctl restart imgmesh-api
  4. 打开 apple-app-site-association。里面的 appIDs 应变成 团队ID.com.imgmesh.app。
  5. 如果手机上已经装过旧的 imgmesh，删掉再从 Xcode 装一次。

地址栏里 #k= 后面的一段是解密密钥。系统或微信有时会把它丢掉。丢掉之后，回到 App，把整段链接粘贴到「打开一份分享」。

发出一组照片

  1. 打开 imgmesh，给这台手机登记一个名称。每台设备只能注册一次，名称也不能和别人重复。再次打开会回到同一个名称。
  2. 点 Sign in with Apple。登录绑在这台设备上，用来发出和撤销。
  3. 标题写成这组照片的名字，例如「三亚」。
  4. 点「选择照片」，可以多选。能发 JPEG、HEIC、PNG 和 WebP，单张不超过 50MB。选图用的是系统选择器，App 不会读取整个相册。
  5. 等加密和上传结束。页面上会出现链接，点「复制链接」，或点「发出链接」交给系统分享。
  6. 把整段链接发给对方。自己先打开一次，确认地址里还有 #k=。

对方查看和保存

对方用手机或电脑的浏览器打开完整链接，就能逐张看、下载单张，或打包下载。HEIC 在浏览器里可能只有下载，原图仍在。

对方也要先登记一个没人用过的名称。查看、下载和存相册都会记在这个名称下。发送者能看到谁查看过、谁下载过，以及哪些手机已经存进相册。

对方也装了 App 时：

  1. 在「打开一份分享」里粘贴完整链接，点「打开」。配好 Team ID 之后，直接点链接也会进来。
  2. 照片出现后，点「保存到相册」。第一次会请求「添加照片」权限，用来写入新照片。
  3. 保存进去的是解密后的原图，之后在系统相册里查看。

照片网格和身份证

一组照片会排成网格，点开一张就能左右翻。每张原图有一个身份证号，由照片内容算出来，同一张照片在不同人手里是同一个号。服务器只保存这个号码和关系，看不到照片本身。

  • 已分享：这张照片被谁发出去过。
  • 谁有这张：分享过或保存过的人。
  • 保存自谁：这份副本是从哪个人那里留下来的。
  • 谁保存了：哪些人把这张照片留了下来。

在「我的资料」里可以写介绍、城市和联系方式。对方在「找人」里用名称、城市或联系方式就能找到你，并看到你分享过、保存过多少张。

移除、撤销，以及谁打开过

  • 「从 imgmesh 移除」把这组照片从这台手机的 imgmesh 列表拿掉，并记一条移除记录。系统相册里已经保存的照片留在原地，服务器上的文件也还在。
  • 「撤销链接」只有发送者能点。撤销后链接失效，服务器上的密文被删除。对方相册里已经保存的副本还在。
  • 发送者打开自己发出的分享，可以在「谁打开过」里看到打开、存进相册和从 imgmesh 移除。
